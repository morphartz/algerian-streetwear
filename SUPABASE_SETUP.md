# Supabase setup for Algerian Streetwear

Supabase URL:
https://sufoaqvnzrwexvuzakla.supabase.co

Set the following environment variables in Vercel and local development:

NEXT_PUBLIC_SUPABASE_URL=https://sufoaqvnzrwexvuzakla.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<your publishable key>

Do not commit the publishable key or any service-role key to the repository.

Use Supabase Auth for the OWNER account. Create the owner account from the Supabase dashboard or a secure local script, then store the corresponding role/profile in the application database.
